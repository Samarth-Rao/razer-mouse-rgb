# razer-mouse-rgb
Control the RGB on Razer mice on macOS without Synapse: turn it off (and undo), set a solid color, spectrum, wave, or fade through your own colors, all saved to the mouse. Works with every Basilisk and other 2017+ Razer mice from OpenRazer's device list (tested on a Basilisk V3).

```
swift razer-rgb.swift off     # also: undo, status, static red, spectrum, wave, cycle red blue, brightness 50
swift razer-rgb.swift         # list all commands
```
